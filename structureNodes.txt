============================================================
NODE TYPE: SPLIT / STRUCTURED ROWS
============================================================

This IS the other multi-column content structure.

Each node can contain multiple children / rows.

Every row in a Split node uses the same selected layout.

Rows stack directly against each other:
- no required gap
- no required margin
- can visually become documentation rows
- tables
- comparison charts
- structured references


SPLIT CHILD OUTPUT: -->

<div
  id="child-<CHILD_ID>"
  class="project-split-row child-<CHILD_ID> customChildClass"
>
  <div class="project-split-child-head">OPTIONAL FULL-WIDTH HTML</div>

  <div class="project-split project-split--MODE">
    <div class="project-split-cell">COLUMN HTML</div>

    <div class="project-split-cell">COLUMN HTML</div>
  </div>
</div>

Full-width area: - optional - accepts arbitrary HTML - not forced into a header
element - may be used as a heading, divider, description, table heading, etc. -
may be used by itself with no lower columns SPLIT MODES / LAYOUTS WE SETTLED ON:
