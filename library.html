Rebuilding Fetch with XMLHttpRequest

Builds a simplified data request from scratch with XMLHttpRequest

Lab / Exploration Complete

Technologies

Technologies not listed yet.

What I Built

This learning project reconstructs the basic request flow behind modern JavaScript data fetching. It creates an XMLHttpRequest, opens and sends a GET request, observes readyState, receives raw JSON as responseText, parses it with JSON.parse(), and accesses the resulting JavaScript objects and arrays. The goal is to understand the mechanics underneath higher-level APIs such as fetch() before returning to the Modern Agenda ECMAScript implementation.
