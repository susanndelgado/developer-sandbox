High-Risk Commands

rm -rf PATH
Permanently removes a directory tree. Verify pwd and the exact path first.
sudo command
Runs with elevated privileges; system-wide damage is possible.
chmod -R / chown -R
Recursive permission/ownership changes can break applications and services.
dd if=... of=...
Raw block copying can overwrite disks. Verify the output device before running.
mkfs.* device
Creates a new filesystem and destroys existing filesystem data on the target.
fsck -y
Automatic repair can modify filesystem structures; use appropriate recovery procedures.
apt/dnf/pacman full upgrades
Large upgrades can change runtimes, services, kernels, and dependencies.
shutdown / reboot
Ends current sessions and running work.
