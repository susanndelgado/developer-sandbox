04

Code & Configuration

Starter configuration plus the focused implementation example.
Focused TypeScript
Implement this behavior first, then alter the input.
database.exec("BEGIN;");
try {
  updateFirst();
  updateSecond();
  database.exec("COMMIT;");
} catch (error) {
  database.exec("ROLLBACK;");
  throw error;
}
Starter Configuration
Keep the project independently buildable.

package.json

{
  "type": "module",
  "scripts": {
    "build": "tsc",
    "start": "npm run build && node --enable-source-maps dist/server.js"
  },
  "devDependencies": {
    "@types/node": "^26.4.0",
    "typescript": "^7.0.2"
  }
}

tsconfig.json

{
  "compilerOptions": {
    "rootDir": "./src",
    "outDir": "./dist",
    "target": "ES2022",
    "module": "ES2022",
    "lib": ["ES2022", "DOM"],
    "types": ["node"],
    "strict": true,
    "sourceMap": true
  },
  "include": ["src/**/*.ts"]
