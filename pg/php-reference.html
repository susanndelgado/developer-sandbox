Request Superglobals

Sessions, Cookies, Passwords & Security

Sessions, cookies, password hashing, CSRF protection, secure randomness, and web security defaults.

Sessions 
session_start();
$_SESSION['user_id'] = $user['id'];
$userId = $_SESSION['user_id'] ?? null;
unset($_SESSION['user_id']);
session_destroy();
NOTE: Call session_start() before reading/writing $_SESSION, and before output
unless your environment uses output buffering.
Regenerate After Login 
session_start();
// after successful authentication
session_regenerate_id(true);
$_SESSION['user_id'] = $user['id'];
NOTE: Regenerating the session ID after authentication helps protect against
session fixation.
Cookies 
setcookie('theme', 'dark', [
'expires' => time() + 86400 * 30,
'path' => '/',
'secure' => true,
'httponly' => true,
'samesite' => 'Lax',
]);
$theme = $_COOKIE['theme'] ?? 'light';
Password Hashing 
$hash = password_hash(
$password,
PASSWORD_DEFAULT
);
if (password_verify($password, $hash)) {
// authenticated
}
if (password_needs_rehash($hash, PASSWORD_DEFAULT)) {
$hash = password_hash($password, PASSWORD_DEFAULT);
}
NOTE: Store the password hash, never the original password.
PASSWORD_DEFAULT lets PHP choose the current recommended default
algorithm.
Csrf Pattern 
session_start();
$_SESSION['csrf'] ??= bin2hex(random_bytes(32));
// form includes token
// compare submitted token on POST
if (!hash_equals(
$_SESSION['csrf'],
$_POST['csrf'] ?? ''
)) {
http_response_code(403);
exit('Invalid request');
}
Generate Secure Random Values 
$token = bin2hex(random_bytes(32));
$id = random_int(100000, 999999);
Web Security Checklist 
• Escape dynamic HTML with htmlspecialchars().
• Validate expected type/range/format of input.
• Use PDO prepared statements for user-supplied SQL values.
• Hash passwords with password_hash().
• Use HTTPS in production.
• Use secure, HttpOnly and SameSite cookie settings where appropriate.
• Use CSRF protection for state-changing browser requests.
• Do not expose secrets in Git, HTML, JavaScript or error pages.
• Restrict file uploads by type, size, filename and destination.
• Return generic production errors; log details server-side.
Do Not Do This 
// SQL injection risk
$sql = "SELECT * FROM users WHERE email = '$email'";
// XSS risk
echo $_GET['name'];
// secret leak
$apiKey = 'real-production-key';

PDO Database Access

PDO connections, prepared statements, CRUD operations, transactions, and practical database access patterns.

Connect - Postgresql 
$pdo = new PDO(
'pgsql:host=localhost;port=5432;dbname=app',
$dbUser,
$dbPass,
[
PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]
);
Connect - Mysql 
$pdo = new PDO(
'mysql:host=localhost;dbname=app;charset=utf8mb4',
$dbUser,
$dbPass,
[
PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]
);
Select One Row 
$stmt = $pdo->prepare(
'SELECT id, name, email FROM users WHERE id = :id'
);
$stmt->execute(['id' => $id]);
$user = $stmt->fetch();
Select Many Rows 
$stmt = $pdo->prepare(
'SELECT id, name FROM users WHERE active = :active ORDER BY name'
);
$stmt->execute(['active' => true]);
$users = $stmt->fetchAll();
Insert 
$stmt = $pdo->prepare(
'INSERT INTO users (name, email) VALUES (:name, :email)'
);
$stmt->execute([
'name' => $name,
'email' => $email,
]);
$id = $pdo->lastInsertId();
Update + Delete 
$stmt = $pdo->prepare(
'UPDATE users SET name = :name WHERE id = :id'
);
$stmt->execute(['name' => $name, 'id' => $id]);
$stmt = $pdo->prepare(
'DELETE FROM users WHERE id = :id'
);
$stmt->execute(['id' => $id]);
Transaction 
try {
$pdo->beginTransaction();
// run related statements
$pdo->commit();
} catch (Throwable $e) {
if ($pdo->inTransaction()) {
$pdo->rollBack();
}
throw $e;
}
Prepared Statement Rule 
Use placeholders for data values: :id, :email, or ?. Do not concatenate user
input into SQL.
NOTE: Prepared statements help prevent SQL injection. Placeholders represent
complete data values; they cannot safely stand in for arbitrary SQL identifiers
such as a table name or ORDER BY column.
Useful Pdo Calls 
• $pdo->prepare($sql) - create prepared statement.
• $stmt->execute($values) - execute with values.
• $stmt->fetch() - next row.
• $stmt->fetchAll() - remaining rows.
• $stmt->rowCount() - affected rows (behavior varies for SELECT by driver).
• $pdo->lastInsertId() - last generated ID where supported.
• beginTransaction(), commit(), rollBack().
Documentation — PDO

https://www.php.net/manual/en/book.pdo.php

PHP cURL — Request Pattern

Core PHP cURL lifecycle, GET requests, authentication headers, status inspection, and request debugging.

The Pattern To Remember 
$ch = curl_init($url);
curl_setopt_array($ch, [
CURLOPT_RETURNTRANSFER => true,
CURLOPT_TIMEOUT => 15,
]);
$response = curl_exec($ch);
if ($response === false) {
throw new RuntimeException(curl_error($ch));
}
$status = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);
NOTE: Think of cURL as: 1) create request handle, 2) set request options, 3)
execute, 4) inspect response/status/error, 5) close or let the handle go out of
scope.
Simple Get 
$url = 'https://api.example.com/users/42';
$ch = curl_init($url);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
if ($response === false) {
throw new RuntimeException(curl_error($ch));
}
$data = json_decode($response, true, 512, JSON_THROW_ON_ERROR);
curl_close($ch);
Get With Query Parameters 
$query = http_build_query([
'q' => 'brown pelican',
'page' => 2,
'limit' => 20,
]);
$url = 'https://api.example.com/search?' . $query;
$ch = curl_init($url);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
curl_close($ch);
Get With Bearer Token 
$ch = curl_init($url);
curl_setopt_array($ch, [
CURLOPT_RETURNTRANSFER => true,
CURLOPT_HTTPHEADER => [
'Accept: application/json',
'Authorization: Bearer ' . $token,
],
]);
$response = curl_exec($ch);
NOTE: Send credentials only over HTTPS. Keep tokens in environment/config,
not in committed source.
Useful Get Options 
• CURLOPT_RETURNTRANSFER => true - return body as a string instead of
printing it.
• CURLOPT_TIMEOUT => 15 - total timeout in seconds.
• CURLOPT_CONNECTTIMEOUT => 5 - connection timeout.
• CURLOPT_FOLLOWLOCATION => true - follow redirects when appropriate.
• CURLOPT_HTTPHEADER => [...] - custom headers.
Inspect Status + Response 
$response = curl_exec($ch);
if ($response === false) {
$message = curl_error($ch);
$number = curl_errno($ch);
}
$status = curl_getinfo(
$ch,
CURLINFO_HTTP_CODE
);
if ($status >= 400) {
// API returned an HTTP error response
}
NOTE: A network/cURL failure and an HTTP 404/500 are different. curl_exec()
can succeed at the transport level while the server returns an HTTP error
status.
Debug Request Metadata 
$info = curl_getinfo($ch);
// examples
$info['http_code'];
$info['total_time'];
$info['content_type'];
Documentation — cURL

https://www.php.net/manual/en/book.curl.php

Search PHP Manual for CURLOPT_* or curl_getinfo.

Reusable Json Request Helper 
function requestJson(
string $method,
string $url,
?array $body = null,
array $headers = []
): array {
$ch = curl_init($url);
$options = [
CURLOPT_RETURNTRANSFER => true,
CURLOPT_TIMEOUT => 15,
CURLOPT_CUSTOMREQUEST => $method,
CURLOPT_HTTPHEADER => array_merge(
['Accept: application/json'],
$headers
),
];
if ($body !== null) {
$options[CURLOPT_POSTFIELDS] = json_encode(
$body, JSON_THROW_ON_ERROR
);
}
curl_setopt_array($ch, $options);
$response = curl_exec($ch);
if ($response === false) {
throw new RuntimeException(curl_error($ch));
}
$status = curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);
return [
'status' => $status,
'data' => json_decode($response, true, 512, JSON_THROW_ON_ERROR),
];
}
NOTE: If you send a JSON body, include Content-Type: application/json in
$headers. Production helpers may also need retry rules, structured errors,
tracing and rate-limit handling.

When Something Fails 
• Syntax error: run php -l file.php and read the first parser error.

not imply HTTP success.

DSN/credentials/driver.

check server logs.

Typical Request/Controller Flow 
<?php
require_once __DIR__ . '/../vendor/autoload.php';
session_start();
$id = filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT);
if (!$id) {
http_response_code(400);

}
$stmt = $pdo->prepare(
'SELECT id, name FROM users WHERE id = :id'
);

if (!$user) {

header('Content-Type: application/json');

$input = json_decode(

true, 512, JSON_THROW_ON_ERROR
);
// validate -> perform work
http_response_code(201);
echo json_encode(['ok' => true], JSON_THROW_ON_ERROR);
} catch (Throwable $e) {
error_log($e->getMessage());
http_response_code(500);
echo json_encode(['error' => 'Server error']);
}

Php Vs Curl In One Sentence 
PHP is the server-side language running your application. The PHP cURL
extension is one way that your PHP code can act as an HTTP client and
call another server or API.
NOTE: This is why cURL can feel different from ordinary form handling: your
PHP application has switched roles from receiving a request to sending one.
Server Receives Vs Php Sends 
• Browser -> PHP: inspect $_GET, $_POST, headers, JSON body, files.
• PHP -> Database: use PDO and SQL.
• PHP -> External API: use cURL (or an HTTP client library).
• PHP -> Browser/API client: send HTML/JSON, headers and HTTP status.
Most-Used Mental Checklist 
• What data came in?
• Is it present, valid and authorized?
• Do I need to escape it now or only when outputting it?
• Am I querying the database? Use prepared statements.
• Am I calling another API? Build the HTTP request deliberately.
• What status code should I return?
• What should be logged if this fails?
• Could this reveal a secret or user data?
