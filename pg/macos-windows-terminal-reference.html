01 — Orientation & Navigation

Orientation & Navigation

Location & Navigation

Get-Location
Show the current working directory.
pwd
Set-Location path
Change to a directory.
cd path
Set-Location ..
Move up one directory.
cd ..
Set-Location ~
Move to the current user's home directory.
cd ~
Set-Location -
PowerShell: return to the previous location.
cd -
Push-Location path
Save the current location and move elsewhere.
pushd path
Pop-Location
Return to the location saved by push.
popd
Orientation & Navigation

List & Discover

Get-ChildItem
List files and folders.
ls
Get-ChildItem -Force
Include hidden/system items.
ls -la
Get-ChildItem -Directory
List directories only.
find . -maxdepth 1 -type d
Get-ChildItem -File
List files only.
find . -maxdepth 1 -type f
Get-Command node
Find the command PowerShell will run.
command -v node
Get-Command node -All
Show all matching command definitions.
type -a node
Get-Help Get-ChildItem
Open built-in command help.
man ls
Get-Help command -Examples
Show command examples.
man command
Orientation & Navigation

History & Screen

Get-History

history
Clear-History

history -p
Clear-Host
Clear the terminal display.
clear
$PSVersionTable
Show PowerShell version and platform details.
zsh --version
$HOME
Show the user's home-directory path.
echo $HOME
$PWD
Read the current PowerShell path object.
pwd

Open from Terminal

Open the current directory in the default file manager.
open .

open file.pdf

Open a URL with the default browser.
open https://example.com

Launch an installed application/CLI with arguments.
code .

02 — Files & Directories

Files & Directories

Create

New-Item -ItemType Directory folder
Create a directory.
mkdir folder
New-Item -ItemType Directory a/b -Force
Create a nested directory path.
mkdir -p a/b
New-Item -ItemType File file.txt
Create an empty file.
touch file.txt
Set-Content file.txt 'text'
Create or replace a text file with content.
printf '%s\n' 'text' > file.txt
Add-Content file.txt 'text'
Append text to a file.
printf '%s\n' 'text' >> file.txt
Files & Directories

Copy, Move & Rename

Copy-Item file.txt copy.txt
Copy a file.
cp file.txt copy.txt
Copy-Item folder dest -Recurse
Copy a directory tree.
cp -R folder dest
Move-Item old new
Move a file or folder.
mv old new
Rename-Item old.txt new.txt
Rename an item.
mv old.txt new.txt
Copy-Item *.txt dest
Copy files matching a wildcard.
cp *.txt dest

Remove Carefully

Remove-Item file.txt
Delete a file.
rm file.txt
Remove-Item folder -Recurse

rm -r folder
Remove-Item folder -Recurse -Force

Remove-Item *.tmp
Delete files matching a wildcard.
rm *.tmp

03 — Read, Search & Transform Text

Read, Search & Transform Text

Read Files

Get-Content file.txt
Print a text file.
cat file.txt
Get-Content file.txt -Head 20
Show the first 20 lines.
head -n 20 file.txt
Get-Content file.txt -Tail 20
Show the last 20 lines.
tail -n 20 file.txt
Get-Content app.log -Wait
Follow a growing log file.
tail -f app.log
Get-Content file.txt -Raw
Read an entire text file as one string.
cat file.txt
Read, Search & Transform Text

Search Text

Select-String 'text' file.txt
Find matching text and line information.
grep -n 'text' file.txt
Get-ChildItem -Recurse -File | Select-String 'text'
Search text recursively through files.
grep -Rni 'text' .
Select-String 'error' *.log -CaseSensitive
Search matching files with case sensitivity.
grep -n 'error' *.log
Select-String '^TODO' file.txt
Search with a regular expression.
grep -n '^TODO' file.txt
Read, Search & Transform Text

Find Files

Get-ChildItem -Recurse -Filter *.js -File
Find files by name pattern.
find . -name '*.js' -type f
Get-ChildItem -Recurse -Directory
Find directories recursively.
find . -type d
Get-ChildItem -File | Where-Object LastWriteTime -gt (Get-Date).AddDays(-1)
Find files modified within the last day.
find . -type f -mtime -1
Get-ChildItem -Recurse -File | Where-Object Length -gt 10MB
Find files larger than a size threshold.
find . -type f -size +10M
Read, Search & Transform Text

Count, Sort & Group

(Get-Content file.txt).Count
Count lines in a text file.
wc -l file.txt

Count pipeline objects.
find . -maxdepth 1 | wc -l
Get-Content file.txt | Sort-Object
Sort lines.
sort file.txt
Get-Content file.txt | Sort-Object -Unique
Sort and remove duplicate lines.
sort -u file.txt
Get-Content file.txt | Group-Object
Group equal lines and count occurrences.
sort file.txt | uniq -c

a && b
PowerShell 7: a || b
Run the second command only if the first fails.
a || b

High-Risk Commands

Remove-Item path -Recurse -Force
Can permanently delete a directory tree. Verify the exact path.
rm -rf path
Stop-Process -Id PID -Force
Force termination can lose unsaved state; use only when normal stop fails.
kill -9 PID
icacls path /grant ...
Permission changes can expose or lock out files; inspect ACLs first.
chmod / chown
winget upgrade --all
Bulk upgrades can change many installed tools; review before running.
brew upgrade
Elevated PowerShell
Administrator/root commands can alter the whole system.
sudo command
