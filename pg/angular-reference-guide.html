Angular Reference Guide

Angular setup, syntax, CLI, components, routing, forms, HTTP, testing, and macOS reference.

Angular at a Glance

Angular is a TypeScript web application framework with components, templates, dependency injection, routing, forms, HTTP, reactive state, testing, and a first-party CLI.

This guide targets Angular 22.1-era standalone applications.

Current Major

Angular 22 is active. Current angular.dev pages are built with Angular 22.1.4.

Node Compatibility

Angular 22 supports Node ^22.22.3, ^24.15.0, or ^26.0.0. Node 24 LTS is a strong macOS baseline.

TypeScript

Angular 22 requires TypeScript >=6.0.0 <6.1.0.

Standalone-first

New components are standalone by default and import template dependencies directly.

Signals

signal() stores state; computed() derives values.

Control Flow

Use @if, @for, and @switch in modern templates.

Zoneless

Zoneless change detection is the default in Angular 21+.

Testing

New CLI projects use Vitest. Run with ng test.

macOS Setup & Installation

Use a Node version manager on a development Mac so projects can target supported Node versions cleanly.

Columns: Purpose / Commands / Notes.

Node + npm

Purpose: Angular CLI runs on Node and npm.

nvm install 24\nnvm use 24\nnode -v\nnpm -v

Notes: Node 24.15+ satisfies Angular 22. Use a project .nvmrc when a team standardizes on one Node major.

Angular CLI

Purpose: install the ng command.

npm install -g @angular/cli\nng version\nwhich ng

Notes: with nvm, routine sudo npm installs should not be necessary.

Editor Tooling

Purpose: completion, diagnostics, navigation, and refactoring.

  • VS Code or WebStorm
  • Angular Language Service
  • Browser DevTools

Use ng completion for CLI shell completion.

Components & Directives

Components define UI with a template. Directives package reusable behavior on existing hosts.

Minimal Component

Component metadata defines selector and template.

Example
import { Component } from "@angular/core";

@Component({
  selector: "app-greeting",
  template: `<h2>Hello Angular</h2>`,
})
export class Greeting {}
External Template / Style

Split larger markup and styles into matching files.

Example
@Component({
  selector: "app-profile",
  templateUrl: "./profile.html",
  styleUrl: "./profile.css",
})
export class Profile {}
Standalone Imports

Import what the template uses.

Example
import { RouterLink } from "@angular/router";

@Component({
  selector: "app-nav",
  imports: [RouterLink],
  template: `<a routerLink="/about">About</a>`,
})
export class Nav {}
Use a Child Component

Import the child class and use its selector.

Example
@Component({
  selector: "app-page",
  imports: [UserCard],
  template: `<app-user-card />`,
})
export class Page {}
Attribute Directive

Package reusable behavior on an existing host element.

Example
@Directive({
  selector: "[appHighlight]",
  host: {
    "(mouseenter)": "active.set(true)",
    "(mouseleave)": "active.set(false)",
    "[class.highlight]": "active()",
  },
})
export class Highlight {
  active = signal(false);
}

Template Syntax

Angular templates are HTML plus expression, binding, control-flow, variable, and pipe syntax.

Interpolation

Render an expression as text.

Example
{{ user.name }}
Property Binding

Bind a DOM or component property.

Example
<img [src]="photoUrl" [alt]="name">
Event Binding

Listen for a DOM event or component output.

Example
<button (click)="save()">Save</button>
<button (click)="select($event)">Select</button>
Class / Style Binding

Bind classes and styles directly.

Example
<div [class.active]="isActive" [style.width.px]="width"></div>
@if

Built-in conditional rendering.

Example
@if (user()) {
  <p>Hello {{ user()!.name }}</p>
} @else {
  <p>Please sign in.</p>
}
@for

Repeat values and track stable identity.

Example
@for (item of items(); track item.id) {
  <li>{{ item.name }}</li>
} @empty {
  <li>No items</li>
}
@switch

Choose among cases; no fallthrough.

Example
@switch (role()) {
  @case ("admin") { <app-admin /> }
  @case ("editor") { <app-editor /> }
  @default { <app-viewer /> }
}
Pipes

Transform values for display. Import standalone pipes used by the template.

Example
{{ total | currency }}
{{ createdAt | date:"medium" }}

Signals & Reactive State

Signals are synchronous reactive primitives. Read a signal by calling it as a function.

signal()

Create writable reactive state and read it by calling the signal.

Example
count = signal(0);
console.log(this.count());
set()

Replace a writable signal value.

Example
this.count.set(5);
update()

Calculate the next value from the previous value.

Example
this.count.update(value => value + 1);
computed()

Create read-only memoized derived state.

Example
first = signal("Susan");
last = signal("Nicole");
fullName = computed(() => `${this.first()} ${this.last()}`);
effect()

Use effects for appropriate imperative side effects. Prefer computed() for derived state.

Example
logCount = effect(() => {
  console.log(this.count());
});

Inputs & Outputs

Inputs pass data into components. Outputs emit custom events to consumers.

input()

Declare an optional signal-based input.

Example
name = input("Guest");
// template reads: {{ name() }}
input.required()

Require the consumer to supply a value.

Example
user = input.required<User>();

<app-user-card [user]="selectedUser()" />
output()

Declare and emit a typed custom event.

Example
saved = output<User>();

save(user: User) {
  this.saved.emit(user);
}
Listen to Output

The parent receives emitted data as $event.

Example
<app-user-form (saved)="handleSaved($event)" />
Older Compatibility APIs

@Input(), @Output(), and EventEmitter remain supported in existing projects.

Example
@Input() user!: User;
@Output() saved = new EventEmitter<User>();

Services & Dependency Injection

Dependency injection lets classes request collaborators rather than constructing them directly.

Root Service

providedIn: root is the standard global singleton pattern.

Example
@Injectable({ providedIn: "root" })
export class UserService {}
inject()

Current Angular style guidance prefers inject() for new code.

Example
private users = inject(UserService);
private router = inject(Router);
Component Provider

Create a service instance scoped to the component subtree.

Example
@Component({
  providers: [DraftService],
  template: `...`,
})
export class Editor {}
InjectionToken

Provide typed configuration or another non-class dependency.

Example
export const API_URL = new InjectionToken<string>("API_URL");

providers: [{ provide: API_URL, useValue: "/api" }]

Router Quick Reference

Routes map URLs to components. Angular uses first-match wins.

Define Routes

CLI routing projects normally use src/app/app.routes.ts.

Example
export const routes: Routes = [
  { path: "", component: Home, title: "Home" },
  { path: "users/:id", component: UserDetail },
  { path: "**", component: NotFound },
];
provideRouter()

Add the router through application providers.

Example
export const appConfig = {
  providers: [provideRouter(routes)],
};
RouterOutlet

The active route component renders at the outlet.

Example
@Component({
  imports: [RouterOutlet],
  template: `<router-outlet />`,
})
export class App {}
RouterLink

Use Angular client-side navigation for internal links.

Example
@Component({
  imports: [RouterLink],
  template: `<a routerLink="/users">Users</a>`,
})
export class Nav {}
Lazy Route

Use dynamic import to split non-primary route code.

Example
{
  path: "settings",
  loadComponent: () => import("./settings/settings").then(m => m.Settings)
}
Programmatic Navigation

Inject Router for navigation triggered by application logic.

Example
private router = inject(Router);

openUser(id: string) {
  this.router.navigate(["/users", id]);
}
Guard

Client guards control navigation but must not be the only authorization layer.

Example
export const authGuard: CanActivateFn = () => {
  const auth = inject(AuthService);
  return auth.isLoggedIn() ? true : inject(Router).createUrlTree(["/login"]);
};

Forms

Reactive forms remain a strong stable default. Template-driven and Signal Forms are also available.

Reactive FormControl

Model-driven explicit form state.

Example
imports: [ReactiveFormsModule]

name = new FormControl("", { nonNullable: true });

<input [formControl]="name">
FormGroup

Group related controls.

Example
profile = new FormGroup({
  name: new FormControl("", { nonNullable: true }),
  email: new FormControl("", { nonNullable: true }),
});
Validators

Attach validation rules to controls.

Example
email = new FormControl("", {
  nonNullable: true,
  validators: [Validators.required, Validators.email],
});
Template-driven / ngModel

Useful for smaller forms. Import FormsModule.

Example
<input [(ngModel)]="name" name="name">
Signal Forms

Angular 21+ signal-based field trees and validation. Evaluate current stability requirements before replacing established reactive forms.

Example
import { form, FormField } from "@angular/forms/signals";

model = signal({ email: "" });
loginForm = form(this.model);

HTTP & API Calls

HttpClient is injectable by default in Angular 21+. Current Angular uses Fetch by default unless configured for XHR.

Inject HttpClient

Prefer a focused API or data service.

Example
private http = inject(HttpClient);
GET

HttpClient methods return RxJS Observables.

Example
getUsers() {
  return this.http.get<User[]>("/api/users");
}
Query Parameters

Pass query parameters through request options.

Example
return this.http.get<User[]>("/api/users", {
  params: { q: term }
});
POST

Send a typed request body.

Example
return this.http.post<User>("/api/users", user);
PUT / PATCH / DELETE

Match the server API contract.

Example
this.http.put<User>("/api/users/42", user);
this.http.patch<User>("/api/users/42", changes);
this.http.delete<void>("/api/users/42");
Configure HttpClient

Use provideHttpClient() for interceptors or other features.

Example
providers: [
  provideHttpClient(withInterceptors([authInterceptor]))
]
Functional Interceptor

Clone immutable requests when adding headers.

Example
export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const token = inject(AuthService).token();
  return next(req.clone({ setHeaders: { Authorization: `Bearer ${token}` } }));
};

RxJS Essentials

Signals fit synchronous state; RxJS remains useful for asynchronous streams and HTTP pipelines.

Observable

A lazy stream that may emit values over time.

Example
users$ = this.http.get<User[]>("/api/users");
AsyncPipe

Template subscription with Angular-managed teardown.

Example
@for (user of users$ | async; track user.id) {
  <p>{{ user.name }}</p>
}
map()

Transform emitted values.

Example
activeUsers$ = this.users$.pipe(
  map(users => users.filter(user => user.active))
);
switchMap()

Switch to a new inner stream and cancel the previous one.

Example
results$ = this.query$.pipe(
  debounceTime(250),
  distinctUntilChanged(),
  switchMap(q => this.http.get<SearchResult[]>("/api/search", { params: { q } }))
);
toSignal()

Expose the latest Observable value as a signal.

Example
users = toSignal(this.users$, { initialValue: [] });

Lifecycle & Cleanup

Use lifecycle hooks when timing matters and DestroyRef for explicit cleanup close to setup code.

ngOnInit

Runs once after Angular initializes component inputs.

Example
ngOnInit() {
  this.load();
}
ngOnChanges

Runs when component inputs change.

Example
ngOnChanges(changes: SimpleChanges) {
  console.log(changes);
}
afterNextRender

Run DOM-dependent work after the next application render.

Example
afterNextRender(() => {
  // DOM-dependent work
});
DestroyRef

Register cleanup close to setup code.

Example
private destroyRef = inject(DestroyRef);

constructor() {
  this.destroyRef.onDestroy(() => cleanup());
}

Testing

New CLI projects use Vitest by default. TestBed remains the Angular-aware testing utility.

Run Tests

Run the workspace test target.

Example
ng test
Simple Unit Test

Basic expectation syntax.

Example
describe("math", () => {
  it("adds", () => {
    expect(2 + 3).toBe(5);
  });
});
TestBed Component

Import a standalone component and create a fixture.

Example
await TestBed.configureTestingModule({
  imports: [Profile],
}).compileComponents();

const fixture = TestBed.createComponent(Profile);
Rendered DOM

Wait for stability before asserting async rendering.

Example
const fixture = TestBed.createComponent(Profile);
await fixture.whenStable();
const el = fixture.nativeElement as HTMLElement;
expect(el.querySelector("h1")?.textContent).toContain("Profile");
HTTP Testing

Mock the HTTP backend instead of calling a real service.

Example
TestBed.configureTestingModule({
  providers: [provideHttpClient(), provideHttpClientTesting()],
});

const httpTesting = TestBed.inject(HttpTestingController);

Modern Implementation Practices

Current defaults for new Angular work plus compatibility guidance for existing projects.

Standalone-first

Use standalone components and application providers for new work. Learn NgModules for maintenance and compatibility.

Prefer inject()

Current Angular style guidance prefers inject() for dependency injection in new code.

Signals for local state

Use writable signals for local state and computed() for derived state.

Track @for items

Track stable identity such as track item.id to minimize DOM replacement.

Keep components focused

Move reusable data and business behavior to services or plain TypeScript functions.

Lazy-load deliberately

Lazy-load routes when it improves initial load cost; measure before over-splitting.

Keep types strong

Use interfaces and types for API payloads, inputs, forms, and route data.

Respect security boundaries

Keep Angular current, do not build templates from user input, and be cautious with APIs that bypass sanitization.

Stay current

Use ng update, release notes, and the Update Guide rather than skipping many major versions.

Troubleshooting Fast Map

Check runtime versions, imports, route order, and workspace context before reinstalling everything.

ng not found

Check which node, which npm, and npm prefix -g. Install the CLI under the active nvm Node version.

Unsupported Node

Run node -v and ng version. Angular 22 needs Node 22.22.3+, 24.15+, or 26.x.

Port 4200 Used

Use ng serve --port 4300. On macOS inspect the owner with lsof -i :4200.

Unknown Element / Pipe

For standalone components, confirm the dependency appears in imports.

Cannot Bind Property

The component or directive input may not be imported, or the binding name may be wrong.

NullInjectorError

A requested dependency has no provider in the active injector hierarchy.

Route Never Reached

Router matching is first-match wins. Put specific routes first and ** last.

CORS Error

CORS is a browser and server policy. Configure the backend or a development proxy.

View Not Updating

In zoneless Angular, state changes need an Angular-recognized notification path such as signals, input changes, or template events.

After an Update

Review migration output, reinstall from the lockfile, run ng test, then run ng build.
