Purpose

Revisit the server-side request patterns used in the original application through a clearer PHP implementation.

Learning Objectives

  • Use cURL deliberately for HTTP requests.
  • Process JSON into usable PHP structures.
  • Compare GET, POST, and request/response concepts.
  • Separate server-side retrieval from rendering.
  • Show static output/source where a public backend is unnecessary.
