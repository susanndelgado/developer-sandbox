TypeScript at a Glance

TypeScript is JavaScript plus static type checking. Types improve editor tooling and catch errors before runtime, then are normally erased from emitted JavaScript.

Current baseline: TypeScript 7.0.2.

What TypeScript Adds

Type annotations, inference, unions, interfaces, generics, narrowing, declaration files, mapped types, conditional types, and editor intelligence.

Not a Runtime

TypeScript does not replace JavaScript. Browsers and Node execute JavaScript. TypeScript checks and transforms source before or alongside runtime tooling.

Core Files

.ts = TypeScript · .tsx = TypeScript + JSX · .d.ts = declarations · tsconfig.json = project configuration.

Preferred Install

npm install -D typescript

Keep TypeScript project-local so each repository controls its compiler version.

Inference

Do not annotate everything. const count = 3 already gives TypeScript useful type information.

Types Disappear

Interfaces, generic parameters, and most type annotations do not exist at runtime. Use real runtime validation for API and user data.

Modules Matter

Compiler module settings must match Node, a browser framework, or the bundler that actually executes the JavaScript.

TypeScript 7

TypeScript 7 uses the new native compiler/tooling foundation and keeps the familiar TypeScript language model while substantially improving compiler performance.

  | "draft"

let result: string | null = null;

let payload: unknown;

Narrow it before using it.

Objects, Interfaces & Type Aliases

Both interface and type can describe object shapes. Type aliases can also represent unions and other non-object types.

Concept / Syntax / Guidance

interface

Named object contract.

interface User {
  id: number;
  name: string;
  active?: boolean;
}

Interfaces can extend other interfaces and participate in declaration merging.

type alias

Name an object, primitive union, tuple, mapped type, or other type expression.

type UserId = string | number;

type Point = {
  x: number;
  y: number;
};

Especially useful for unions, intersections, and constructed types.

Optional Property

The property may be absent.

interface User {
  nickname?: string;
}

Optional does not mean every consumer can safely assume a value exists.

readonly Property

Prevent assignment through that typed reference.

interface User {
  readonly id: number;
}

This is compile-time protection, not automatic Object.freeze runtime behavior.

Index Signature

Unknown property names with a consistent value type.

interface Scores {
  [name: string]: number;
}

Useful for dictionary-like objects.

Intersection

Require multiple contracts at once.

type Timestamped = {
  createdAt: Date;
};

type SavedUser =
  User & Timestamped;

Good for clear composition; avoid unreadably deep intersections.

satisfies

Check a value against a type while preserving useful inference.

const routes = {
  home: "/",
  users: "/users"
} satisfies Record<string, string>;

Often preferable to a broad type assertion for configuration objects.

Functions

Type function boundaries where the contract matters. Let obvious implementation details infer naturally.

Parameters + Return

Basic function contract.

Example 
function add(a: number, b: number): number {
  return a + b;
}
Optional Parameter

The value may be undefined.

Example 
function greet(name?: string): string {
  return `Hello ${name ?? "friend"}`;
}
Default Parameter

Provide a value when omitted.

Example 
function page(size = 20): number {
  return size;
}
Rest Parameters

Collect remaining arguments into an array.

Example 
function sum(...values: number[]): number {
  return values.reduce((a, b) => a + b, 0);
}
Function Type

Describe a callable value.

Example 
type Formatter =
  (value: number) => string;
Generic Function

Preserve a relationship between input and output types.

Example 
function identity<T>(value: T): T {
  return value;
}
Generic Constraint

Require a minimum shape while keeping the specific input type.

Example 
function getId<T extends { id: string | number }>(
  value: T
) {
  return value.id;
}

Unions & Narrowing

A union means a value can have several possible types. Narrowing proves which member is present before member-specific operations are used.

Union

Model explicit alternatives.

Example 
let id: string | number;
typeof

Narrow primitive-like values.

Example 
function format(value: string | number) {
  if (typeof value === "string") {
    return value.toUpperCase();
  }

  return value.toFixed(2);
}
Array.isArray

Narrow array alternatives.

Example 
if (Array.isArray(value)) {
  console.log(value.length);
}
in Operator

Check whether a property exists on an object-union member.

Example 
if ("meow" in pet) {
  pet.meow();
} else {
  pet.bark();
}
instanceof

Narrow class instances at runtime.

Example 
if (value instanceof Date) {
  return value.toISOString();
}
Discriminated Union

One of the best patterns for modeling application states.

Example 
type Result =
  | { kind: "success"; data: User[] }
  | { kind: "error"; message: string };

function render(result: Result) {
  if (result.kind === "success") {
    return result.data;
  }

  return result.message;
}
Type Predicate

Create a reusable custom type guard.

Example 
function isUser(value: unknown): value is User {
  return (
    typeof value === "object" &&
    value !== null &&
    "id" in value
  );
}

Generics

Generics let reusable code preserve relationships between types instead of collapsing everything into a broad base type.

Identity

Return the exact input type.

Example 
function identity<T>(value: T): T {
  return value;
}
Array Element

Reuse one implementation across element types.

Example 
function first<T>(
  items: readonly T[]
): T | undefined {
  return items[0];
}
Multiple Parameters

Represent independent type positions.

Example 
function pair<K, V>(
  key: K,
  value: V
): [K, V] {
  return [key, value];
}
keyof Constraint

Make a key depend on the object type.

Example 
function get<T, K extends keyof T>(
  obj: T,
  key: K
): T[K] {
  return obj[key];
}
Generic Interface

Parameterize reusable structures.

Example 
interface ApiResponse<T> {
  data: T;
  status: number;
}

type UserResponse =
  ApiResponse<User[]>;

Type Operators & Type Construction

Build new types from existing types and values.

keyof 
type UserKey =
  keyof User;
typeof 
const config = {
  port: 3000
};

type Config =
  typeof config;
Indexed Access 
type UserName =
  User["name"];
as const 
const roles =
  ["admin", "user"] as const;

type Role =
  typeof roles[number];
Mapped Type 
type Flags<T> = {
  [K in keyof T]: boolean;
};
Conditional Type 
type Element<T> =
  T extends readonly (infer U)[]
    ? U
    : T;
Template Literal Type 
type EventName =
  `user:${"created" | "deleted"}`;

Classes & OOP Syntax

TypeScript classes are JavaScript classes plus compile-time type features.

Basic Class

Typed fields and constructor.

Example 
class User {
  name: string;

  constructor(name: string) {
    this.name = name;
  }
}
Access Modifiers

public, protected, and private are TypeScript visibility tools.

Example 
class Account {
  public name = "";
  protected balance = 0;
  private cache = new Map();
  #secret = "runtime private";
}
readonly

Prevent reassignment in typed code.

Example 
class Config {
  constructor(
    readonly apiUrl: string
  ) {}
}
implements

Check that a class instance conforms to an interface.

Example 
interface Printable {
  print(): void;
}

class Report implements Printable {
  print(): void {}
}
abstract

Create a base contract that cannot itself be instantiated.

Example 
abstract class Shape {
  abstract area(): number;
}

Modules, Imports & Exports

Compiler module settings must agree with how Node or your bundler really loads JavaScript.

Named Export / Import

Standard ESM syntax.

Example 
// math.ts
export function add(
  a: number,
  b: number
) {
  return a + b;
}

// app.ts
import { add } from "./math.js";
Default Export

One default export per module.

Example 
export default class App {}

import App from "./app.js";
Type-only Import

Make type-only dependencies explicit.

Example 
import type {
  User
} from "./types.js";
Mixed Import

Runtime and type-only names together.

Example 
import {
  save,
  type SaveOptions
} from "./save.js";
Dynamic Import

Load a module on demand.

Example 
const module =
  await import("./feature.js");

module.run();

Async, Promises & Fetch

TypeScript adds types to JavaScript asynchronous behavior; Promise mechanics remain JavaScript runtime behavior.

Promise Return Type

An async function returns a Promise.

Example 
async function loadUser(
  id: string
): Promise<User> {
  return getUser(id);
}
await

Await a Promise inside an async/module context.

Example 
const user =
  await loadUser("42");
Promise.all

Run independent asynchronous work together.

Example 
const [user, posts] =
  await Promise.all([
    getUser(),
    getPosts()
  ]);
External JSON

API data is runtime data. Treat it as unknown until validated.

Example 
const response =
  await fetch("/api/users");

const raw: unknown =
  await response.json();
Error Narrowing

Thrown values are not guaranteed to be Error objects.

Example 
try {
  await run();
} catch (error: unknown) {
  if (error instanceof Error) {
    console.error(error.message);
  }
}

DOM & Browser TypeScript

DOM declarations provide strongly typed elements, browser events, fetch, URL, storage, and related APIs.

querySelector

Specify the expected element shape.

const input =
  document.querySelector<HTMLInputElement>(
    "#name"
  );

if (input) {
  console.log(input.value);
}
Events

Narrow element-specific event values.

input?.addEventListener(
  "input",
  event => {
    const target =
      event.currentTarget
      as HTMLInputElement;

    console.log(target.value);
  }
);
Forms

Typed browser form element.

const form =
  document.querySelector<HTMLFormElement>(
    "#profile"
  );

form?.addEventListener(
  "submit",
  event => {
    event.preventDefault();
  }
);
localStorage

Stored values are strings and may be absent.

const theme =
  localStorage.getItem("theme");

// string | null

Best Implementation Practices

TypeScript is most useful when it makes boundaries, state, and relationships clearer instead of adding annotations everywhere.

Install Locally

Pin TypeScript in each repository and run it through package scripts or npx.

Keep Strict Checking

Fix or narrow difficult types instead of disabling strictness across the project.

Prefer Local Inference

Annotate public boundaries, external data, domain models, and non-obvious generic relationships. Let simple local values infer.

Model States with Unions

Discriminated unions are usually safer than several loosely related state booleans.

Prefer unknown to any

unknown requires narrowing before use. any simply disables useful checking.

Assertions Are Not Validation

value as User changes what the compiler believes. It does not change or validate the runtime value.

Use import type

Make type-only dependencies explicit and prevent confusion between runtime and compile-time imports.

Match the Runtime

Use Node-aware module settings for Node and bundler-aware settings for bundler projects. Do not copy tsconfig options blindly.

Troubleshooting Fast Map

Check compiler version, effective configuration, included files, and module resolution before changing types blindly.

tsc Not Found

Install locally:

npm install -D typescript
npx tsc --version
Wrong Version

Compare npx tsc --version with tsc --version. Use the local version for project work.

tsconfig Seems Ignored

Passing source files directly to tsc can bypass project configuration. Run npx tsc or use -p.

Unexpected File Included

Use npx tsc --explainFiles or --listFilesOnly.

Cannot Find Module

Run npx tsc --traceResolution. Check file extensions, package exports, and module resolution mode.

Cannot Find process

Install @types/node and add "types": ["node"] to Node projects.

Possibly undefined

Check, narrow, default, or redesign the value. Do not automatically silence the warning with !.

Property Missing on Union

Narrow with a discriminant, typeof, in, instanceof, or a custom type guard.

Wrong Output Folder

Inspect rootDir, outDir, and npx tsc --showConfig.

Editor Differs from CLI

Make sure your editor is using the workspace TypeScript version rather than an older bundled compiler.
