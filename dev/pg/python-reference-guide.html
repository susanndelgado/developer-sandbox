Python uses indentation instead of braces. Statements normally need no semicolon.

05 — Control Flow & Loops

def add(a, b):
    return a + b

def greet(name="Guest"):
    print(f"Hello {name}")

def typed_add(a: int, b: int) -> int:
    return a + b

count: int = 5
birds: list[str] = ["Heron", "Egret"]

Pattern: def function_name(parameters):. A function without an explicit return value returns None. Type hints aid readability and tooling.

def • return • annotations

06 — Functions & Type Hints

class Painting:
    def __init__(self, title, price):
        self.title = title
        self.price = price

    def display(self):
        print(f"{self.title}: ${self.price}")

painting = Painting("Blue Heron", 125)
painting.display()

import math
print(math.sqrt(25))

from math import sqrt

if __name__ == "__main__":
    print("Run directly")

__init__ initializes an instance. self refers to the current instance. Use import to load modules.
