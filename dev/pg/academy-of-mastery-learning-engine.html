Purpose / Learning

Purpose

Turn the Academy of Mastery learning method into software that can structure, resume, and document long-term study.

Learning Objectives

  • Model topics, sections, lecture units, reference units, and optional exercise units.
  • Require explicit progression rather than automatically advancing through material.
  • Store expert resources separately from lecture content.
  • Track progress and resumption points across projects and subjects.
  • Support short focused study sessions with natural stopping points.
  • Connect study evidence to Sandbox projects, labs, and reference guides.
  • Keep resource provenance and ownership/access notes visible.

Implementation Scope

Planned behaviors, architecture decisions, and evidence this project should produce.
Curriculum engine
Represent the exact learning hierarchy used by the Academy.
  • Topic.
  • Section.
  • Section introduction lecture.
  • Lecture unit.
  • Reference unit.
  • Optional exercise unit.
Progress gates
Progress should be intentional rather than automatic.
  • Unit completion state.
  • Section completion state.
  • Ready-to-continue confirmation.
  • Resume point.
Reference library
Resources remain first-class learning objects.
  • Expert/teacher.
  • Video/book/PDF/site.
  • Free/owned/purchase status.
  • Direct source link.
  • Topic/section mapping.
Session planning
Support focused work intervals without losing continuity.
  • 30–45 minute technical-study blocks where appropriate.
  • Natural stopping point.
  • What was completed.
  • What resumes next.
Project integration
Connect study to implementation evidence.
  • Projects that use the skill.
  • Reference guides created from study.
  • Labs used for practice.
  • Mastery notes.
Potential modules
The system can grow without requiring separate disconnected apps.
  • Curriculum Builder.
  • Mastery Progress Ledger.
  • Learning Resource Mapper.
  • Study Resume Dashboard.

Design Principle

The system should preserve deliberate approval between units/sections rather than behaving like an autoplay course.

Relationship

Developer Sandbox can present completed learning evidence; this engine would manage the learning workflow itself.
