Page Structure

The Record Header is always first. Everything below it can be added, removed, edited, and moved up/down.

Node types: Nav / Links, Display / Preview, Standard, Documentation, Grid / Boxes, and Split / Structured Rows. Existing nodes can be changed to another node type from inside the node editor. Standard and Documentation use full-width stacked children. Grid and Split are the multi-column structures.
Save or open an entry, then choose + Add Node.
Editing nodes and children. Save the Entry first, then add or select a node. Each node has its own form and can be removed, reordered, or converted to another node type. Children can be added, removed, and reordered. Saved children can also be moved to another compatible parent node.

Standard / Documentation child types: Standard HTML, Note / Aside, or Code Example. Behavior: None, Link, or Collapsible. Behavior None remains one full-width content column. Link and Collapsible add only the narrow action area on the right.

HTML fields include syntax highlighting, tag completion, auto-close, bracket matching, line numbers, and a Format HTML button when the helper libraries are available.
