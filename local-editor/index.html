Page Structure

The Record Header is always first. Add a Parent Node to create a new top-level section. Select a Parent Node to add children beneath it. Parent and Child Nodes can be edited, reordered, moved, or removed. Entry editing is separate from Node editing.

Node types: NAV / LINK, DISPLAY / PREVIEW, STANDARD, SPLIT, GRID / BOXES, and CODE / EXAMPLES. A node with no parent is a top-level Parent Node. A node assigned to another Parent Node is a Child Node.

Save or open an entry, then choose + Add Parent Node.
Editing Parent and Child Nodes. Save the Entry first, then add or select a Parent Node. Select a Parent Node to add a Child beneath it. Every saved node can be moved to another Parent Node, or set to None — Make Top-Level Node.

Parent Node Type + Mode controls child output. STANDARD supports Full Width, Collapsing List, and Link List. SPLIT supports its layout/mode combinations. GRID / BOXES uses its responsive grid. NAV / LINK creates navigation or action links. CODE / EXAMPLES renders raw Code data inside generated <pre><code> markup. DISPLAY / PREVIEW has no children.

Major HTML fields include syntax highlighting, tag completion, auto-close, bracket matching, line numbers, Format HTML, and optional semantic/accessibility assist.
